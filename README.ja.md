# IIDX 33 NOTES RADAR Cap Unlock

> ## ⚠️ 重要警告（オンラインサーバー）
>
> **オンラインサーバーに接続している間は、絶対に `EnablePlayerCap` を無効にしないでください。**
> 無効にするとプレイヤーレーダー（PNR）が 200.00 を超え、サーバーに異常値として記録され、
> **アカウント停止（BAN）につながる可能性があります**。
> オンラインでプレイする際は必ず `EnablePlayerCap=1` を維持してください。
> 変更を検討してよいのは完全にオフラインの環境だけです。

[简体中文](README.md) | [English](README.en.md) | **日本語** | [한국어](README.ko.md)

beatmania IIDX 33 Sparkle Shower (LDJ) の NOTES RADAR 上限解除プラグインです。

ゲームは譜面レーダーの 6 軸を **200.00** で強制的にクリップしています。本プラグインは
その上限を撤廃し、選曲画面とサブ画面に実際の値（200 超えを含む）を表示させます。
一方で、**プレイヤーレーダー（PNR）は集計・送信時に従来どおり 200.00 でキャップ**されます。

---

## 機能

| 機能 | 内容 | 設定項目 |
|---|---|---|
| 譜面レーダー上限解除 | 選曲画面 / サブ画面に実値を表示（>200.00） | `EnableCap` |
| プレイヤーレーダーのキャップ | PNR の集計・送信は 200.00 のまま | `EnablePlayerCap` |
| 手動再計算 | `Ctrl+Alt+R` でゲーム自身の全譜面レーダー再計算を実行 | `EnableRecalcKey` |

## 仕組み

各軸のレーダー値は、生の指標に **4 分割の区分線形正規化関数**を適用して得られます。
出力は `[0, 2.0]` で、`10000` を掛けて 1/100 固定小数点の整数として保存されます。
200.00 という上限は `min(v, 200)` のような命令ではなく、**最後の区間の終点**
（`1.75 + 0.25 × 1.0 = 2.0`）です。最後の区間にある「比率を 1.0 にクランプする」
分岐を NOP にすると、値は線形に外挿され、単調性を保ったまま 200.00 を超えます。

リバースエンジニアリングの詳細（パラメータ表、データ構造、検証方法）は
**[docs/algorithm.md](docs/algorithm.md)** を参照してください。

## 対応環境

- **IIDX 33 Sparkle Shower**（bm2dx.dll 18,467,992 バイト）と
  **IIDX 34 ZINRAI**（bm2dx.dll 18,200,216 バイト）に対応。起動時にモジュールの
  `SizeOfImage` で自動判別します。
- DLL は各パッチ箇所のバイト署名を検証し、一致しない場合はその変更をスキップして
  ログに記録します（ゲームを壊しません）。
- spice2x のプラグインと共存します。`-k` 引数で読み込みます。

## ビルド

C コンパイラ（MSVC / clang / zig）であれば何でも構いません:

```bat
zig cc -target x86_64-windows-gnu -shared -O2 -o notesradar.dll src\notesradar.c
```

または `build.bat` を実行してください。

## インストール

1. `notesradar.dll` と `notesradar.ini` を `bm2dx.dll` と同じフォルダに置く;
2. spice2x の起動引数に次を追加する:

   ```
   -k notesradar.dll
   ```

3. ゲームを起動すると `notesradar.log` が生成されます。正常時は次のように記録されます:

   ```
   notesradar loaded (build ...; cap=1 pnr=1 2dx=0)
   cap removal: 3/3 sites patched
   addBinary hook installed ...
   all done
   ```

## 設定

`notesradar.ini`

```ini
EnableCap=1          ; 譜面レーダー上限解除
EnablePlayerCap=1    ; PNR 集計の 200.00 キャップ（オンライン時は必ず 1）
Enable2dxCompat=0    ; 2dxtra 互換（実験的）
EnableRecalcKey=1    ; Ctrl+Alt+R で全譜面再計算
```

## 既知の制限

- **2dxtra の特殊譜面生成**（kichiku / kiraku / all scratch）は譜面レーダーを読み取り、
  `200.00 以下` を前提としています。`EnableCap` を有効にしたままこれらの譜面タイプへ
  切り替えるとクラッシュする場合があります（本質的な競合です）。
  必要な場合は `EnableCap=0` にしてゲームを再起動してください。
- `Enable2dxCompat` は実験的機能です（2dxtra の書き戻しをフック）。2dxtra のコードは
  Windows x64 ABI に従っておらず（r9 が保存される前提、呼び出し元のスタックが未整列）、
  何度試しても不安定なため**デフォルトで無効**です。
- レーダー値が 200 を超えると六角形が枠外に描画されます（ゲームは `/200` で正規化して
  描画します）。これは想定通りの挙動です。
